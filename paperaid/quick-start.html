5-minute guide

Pick a task. Choose a file. Save a new copy.

Most PaperAid jobs follow the same simple pattern. Start here before opening the detailed manual.

Quick startStartScanPhoto to PDFID photoSave safely

1. Start from Home

  1. Open PaperAid.
  2. Choose the job you want: Scan, Photo to PDF, Passport / ID photo, Resize, Compress or PDF toolkit.
  3. Pick the source file when PaperAid asks for it.
  4. Check the preview before saving.
PaperAid uses user-driven pickers and save dialogs. You choose the source and destination.

2. Scan a paper document

  1. Choose Scan document.
  2. On Android, take a camera photo or choose an existing image. On Windows, choose an image file.
  3. Crop or use the whole page.
  4. Pick the readability mode you prefer.
  5. Add more pages if needed, reorder them, then save the PDF.

3. Put photos into one PDF

  1. Choose Photo to PDF.
  2. Select several photos.
  3. Drag them into the correct order.
  4. Choose the page size, then export.

4. Prepare a passport or ID photo

  1. Choose a country preset or Custom size.
  2. Move and zoom the photo manually inside the required frame.
  3. If needed, remove the background on-device.
  4. Use Erase for leftover background and Restore if part of the person was removed.
  5. Choose a background color, then export the photo or print sheet.
PaperAid helps prepare a photo. It does not guarantee acceptance by a passport, visa or identity authority. Verify the exact current requirement before submission.

5. Save safely

  • Prefer saving a new copy rather than replacing the only copy of an important original.
  • Open the exported file once before uploading it to a government or application portal.
  • For portals with a KB limit, use Image Compress after resizing.
  • For sensitive documents, only share the final file with the intended recipient.
