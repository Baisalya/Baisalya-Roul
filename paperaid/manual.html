User manual

PaperAid, from first file to final export.

Search by task or jump directly to a tool. The manual is written for normal users first, with advanced details only where they help.

Home, search and navigation

Use Home for the common tasks. All Tools groups the current tools into Scan & make PDF, ID photo & forms, Photo tools and PDF tools. Favorites and recent tools help you get back to repeated jobs quickly.

Scan document

Choose a camera photo or image, crop or use the whole page, choose Color / Gray / B&W-style cleanup, add multiple pages, reorder them and export a PDF. Android can capture with the camera; Windows uses file selection.

Photo to PDF

Select multiple photos, preview thumbnails, drag them into the correct order, choose A4 / Letter / Legal and export one PDF.

Passport / ID photo

Choose a preset or Custom size. Current country references include India, United States, United Kingdom, Canada, Australia, Singapore, Japan and Germany. The app shows the dimensions and where available head-size guidance or an official reference link.

Move, zoom and fit the person

The ID-photo frame stays at the target aspect ratio. Drag to reposition. On Android, pinch to zoom. On Windows, mouse-drag and mouse-wheel work alongside the zoom control. Quick actions can show the whole photo, fill the frame or center the person.

Remove and refine background

Background removal runs on-device. After removal, use Manual refine. Erase removes leftover background; Restore brings back parts of the original person. A circular brush pointer shows the active size. Adjust brush size and edge softness, zoom in for detail, pan when needed, and use Undo / Redo / Reset.

Choose the background color

Start with the visual color palette—White, Soft White, Gray, Light Blue, Blue, Red and additional grouped colors. Use the advanced exact-color controls only when an authority or portal gives you a specific color requirement.

Signature resize

Choose Signature resize for signatures used by forms and exam/application portals. Select the image, choose the required dimensions and format, then save a new copy.

Resize image

Choose pixels for web/application portals or mm/cm/inches for physical size. Whole photo keeps all content inside the target area. Fill the box fills the target dimensions and may crop outer edges.

Compress image

Choose a common target such as 50 KB, 100 KB, 200 KB, 300 KB, 500 KB or 1 MB, or enter a custom limit. Very small targets can reduce visual quality.

PDF toolkit

The PDF toolkit includes Join PDFs, Save selected pages, Remove pages, Rotate pages, Smaller PDF, Much smaller PDF, Add watermark text and Add a password.

Privacy and local files

PaperAid does not require an account for the core tools. Selected document/photo content is processed locally. Small remote metadata requests may be used for updates and business configuration; they do not contain document or photo bytes.

Future Pro / rewarded access

The first public release is configured free with premium locks and rewarded ads disabled. The app already contains dormant store/rewarded-access infrastructure so future business configuration can activate eligible features without changing document-processing logic.

Troubleshooting

If a file does not open, try another copy or format. If export fails, choose a different destination and confirm available storage. If background removal misses an edge, zoom in and use Manual refine. If a portal rejects a photo, compare the portal's current size, background and file-size rules against your export.

Important note about official photo requirements

PaperAid is a preparation utility, not an issuing authority. Passport, visa, ID and application photo rules can change, and some processes require professional capture, photographer certification or portal-specific digital framing. Always verify the current requirement of the authority receiving the photo.
