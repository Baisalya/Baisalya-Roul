Support

Start with the simple fix.

Use the quick checks below before sending a support message. For privacy, do not email sensitive documents, IDs, passwords, OTPs or payment information.

Common fixes

1

File will not open

Try another copy or confirm the file type is supported by the tool you selected.

2

Export will not save

Choose another folder or filename and confirm the device has free storage.

3

Background edge looks wrong

Use Manual refine, zoom in, then Erase or Restore with a smaller softer brush.

4

Portal rejects photo

Check the portal's current dimensions, background, file type and KB limit. PaperAid cannot override an authority's rules.

Contact

Need developer help?

Describe the screen, what you expected, what happened, your platform and PaperAid version. A screenshot of the app UI is usually enough—do not send the private document itself unless it is safe and truly necessary.
