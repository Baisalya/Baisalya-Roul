# EduSheet Website Premium Teacher Progress + Marketing Upgrade

## What was done
This update applies all three requested improvements:
1. Teacher progress visuals upgraded to a more premium glassmorphism style.
2. Animated count-up and progress-fill effects added using plain JavaScript.
3. Homepage strengthened with a real teacher workflow story section.

## Design intent
The website should feel more like a polished product landing page and better communicate that EduSheet is a complete teacher workspace, not only a paper maker.

## Technical notes
- All numbers and progress values are illustrative static marketing values.
- Animations are viewport-triggered and respect reduced-motion settings.
- No backend or live data assumptions were added.
