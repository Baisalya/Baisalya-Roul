1. Home Screen

The home screen is your teacher tool hub.

  • Create Paper
  • Saved Papers
  • OMR Generator
  • Question Bank
  • PDF/Word Reader
  • Word Converter
  • Scientific Calculator
  • Settings

2. Create Paper / Paper Composer

Paper setup

Configure school/institution name, exam title, duration, maximum marks, date, student name line, roll line, school logo, custom header fields and general instructions.

Sections

Add, rename, instruct and remove sections such as Section A, B and C.

Question types

Author multiple choice, descriptive, fill in the blank, multiple select, true/false, one-word, short answer, long answer, numerical, mathematical expression, assertion/reason, image/diagram and custom questions.

Marks, optional/OR and rich text

Set marks per question, enable Optional/OR choice where required, and use common rich-text controls without turning the screen into a generic office editor.

3. Math Keyboard — Main USP

Normal workflow: Put the cursor inside the question → tap Math → build the expression visually → Add/Save formula → continue typing. Tap an existing inline formula to edit it again.

The source includes specialized catalogs for Basic mathematics, Operators, Functions, Trigonometry, Calculus, Matrices, Sets, Statistics, Greek, Brackets, Arrows, Templates, Geometry, Physics, Chemistry and Miscellaneous symbols.

Semantic search

You can search teacher-language meanings such as fraction, numerator, wavelength, standard deviation, perpendicular and equilibrium instead of searching by LaTeX command.

Smart palettes, favorites and recents

Contextual shortcut ribbons exist for common areas such as Calculus, Physics, Chemistry, Statistics, Geometry and Trigonometry, while recent and favorite symbols speed up repeated work.

Advanced source fallback

Advanced source editing exists for edge cases, but it is not the default teacher workflow. Older expressions are designed to preserve source/fallback information rather than silently losing content.

4. Geometry Studio

Use lines/arrows, triangle, right triangle, square, rectangle, parallelogram, trapezium, rhombus, pentagon, hexagon, editable polygon, circle, semicircle, coordinate axes, number line, cube, cuboid, cylinder, cone and sphere. Labels and common construction marks are also supported.

5. Scan Text / OCR

  1. Choose Camera or Gallery.
  2. Crop the relevant question.
  3. Enable Hindi Support for Devanagari when needed.
  4. Let OCR recognize the text.
  5. Proofread and edit the result.
  6. Tap Use This Text.
Important: OCR is a starting point. Proofread mathematical notation and scanned text before using it in a real exam.

6. Question Bank

Question Bank entries can retain subject, chapter, difficulty, tags, favorite status, answer/options, math expressions and richer question metadata.

Insert into a paper

Open Question Bank from Paper Composer, select one or more questions and insert independent copies.

Save back to the bank

A paper question can be saved as a reusable master question, with duplicate-content warning support.

Current limitation: The separate Generate Random Questions dialog can create a randomized preview, but its current “Use in Paper” action is not wired. Use the normal Question Bank picker for production work.

7. Paper Styles

Visible built-in styles include School Formal, School Compact, Board Exam Classic, Board Exam Structured, University Semester, Institutional Modern, Minimal Print, Coaching Mock, Primary Friendly and Primary Worksheet. Supported customizations include text density, border, heading alignment and typography sizes.

8. Preview, Save & Export

Paper Composer includes Undo, Redo, Paper outline, Preview, Save now, Export PDF and Export Word.

  • PDF: print-ready distribution.
  • Word: editable copy for another teacher or institution.
Public claim rule: Market the normal Create Paper export surface as PDF + Word. Other Office-related services in the code are not the normal question-paper export surface.

9. Saved Papers

Search by title or school, sort by newest/oldest, title A–Z or marks, then edit, export PDF, export Word or delete.

10. OMR Generator

Configure school name, exam name, question count, 2/3/4/5 answer options, roll field, section field and optional QR/barcode data, then generate/export PDF.

11. Document Reader

Rich/native in-app support includes PDF, DOCX, XLSX, CSV, PPTX and TXT. Legacy DOC, RTF, ODT, XLS, ODS, PPT and ODP may be recognized but intentionally handed to a compatible external app instead of pretending perfect native rendering.

12. Word Converter

Available workflows include DOCX → PDF, PDF → Word (Exact Look), PDF → Word (Editable Text), and TXT → Word. Exact Look prioritizes visual similarity; Editable Text prioritizes selectable/editable text and can use OCR for scanned pages.

13. Scientific Calculator

Scientific functions, degree/radian switching, shift functions, hyperbolic mode, live result preview, previous answer, history and a science formula catalog are included.

14. Settings

Current available areas include Dark Mode, Help/feedback information, developer details and Privacy Policy.

Coming Soon: Download AI Model, Backup Cloud and Import/Export Data. Do not advertise these as available yet.

15. Offline & Local Data

The current architecture is offline-first: saved papers and Question Bank are local, document processing centers on local files and core paper creation does not require an EduSheet account. External apps are opened only for explicit user actions such as unsupported legacy files, developer links or UPI/payment actions.

16. Help & Support

Before public launch, verify the support email shown in the app and website. The current source uses support@edusheet.com; the mailbox/domain should be confirmed before publishing.
