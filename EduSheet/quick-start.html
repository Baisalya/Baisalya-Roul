EduSheet›Quick Start

Your first paper in 4 simple steps.

No long setup. Start with a question, add the special content you need, then preview and export.

Pehla paper sirf 4 simple steps mein.

Long setup nahi. Question se start karo, special content add karo, phir preview aur export.

01

Tap “Create Paper”

Open EduSheet and choose Create Paper. Add school/exam details when needed.

“Create Paper” tap karo

EduSheet open karo aur Create Paper choose karo. Zarurat ho to school/exam details set karo.

02

Write your question naturally

Tap Write first question, choose the question type and marks, then type normally. Need a formula? Tap Math. Diagram? Geometry. Printed question? Scan text.

Question naturally likho

Write first question tap karo, type aur marks choose karo. Formula ke liye Math, diagram ke liye Geometry, printed question ke liye Scan text.

03

Build the paper

Save the question, add more questions or sections, or insert reusable content from Question Bank.

Paper build karo

Question save karo, aur questions/sections add karo, ya Question Bank se reusable questions insert karo.

04

Preview & export

Open Preview, choose the paper appearance you want, then export as PDF or Word.

Preview & export

Preview kholo, paper style choose karo aur PDF ya Word export karo.

Pro tip: Tap an existing inline formula to edit it again.
