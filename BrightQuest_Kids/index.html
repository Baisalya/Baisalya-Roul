Questions parents ask

Clear answers before you install.

BrightQuest keeps the learner experience simple and the grown-up details explicit.

Does BrightQuest need an internet connection?+

Core learning, local profiles, progress, rewards, narration settings and game content are designed to work offline. External developer/support links open outside the app when a parent chooses them.

Does the app show ads?+

No. The current app does not include an advertising SDK or child-facing advertising.

Does a child need an account?+

No child account is required. Parents can create local learner profiles using a name or nickname, stage/class and avatar.

What happens if the parent PIN is forgotten?+

The parent lock includes a recovery-code flow designed to reset the PIN without deleting learner progress. The recovery code should be kept outside the app.

Are class packs for sale now?+

No public paid class-pack release is represented on this site. Store purchase controls remain a release-stage feature until production verification is complete.
