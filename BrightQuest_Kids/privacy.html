Privacy Policy

BrightQuest Kids is designed to keep a child’s learning experience local, simple and parent-guided.

1. Overview

This Privacy Policy applies to the BrightQuest Kids application for Android and Windows and the official BrightQuest Kids pages hosted on baisalya.com. It explains what information the current app handles, where that information is stored, and what parents can control.

No adsThe current app does not include an advertising SDK.
No remote analyticsThe current app does not send child learning activity to a BrightQuest analytics service.
No child accountCore learning does not require an online child account or email sign-in.
Local-firstLearner profiles, progress and settings are stored on the device.

3. Information handled inside the app

The current app can store the following information locally on the device when a parent or child uses the related feature:

  • Learner profile: a parent-chosen name or nickname, avatar, learner stage and class selection.
  • Learning progress: completed activities or levels, answers/results needed for progress, mission state, mastery/review evidence, stars, achievements, rewards and cosmetic selections.
  • Parent settings: healthy-play controls, learning goals, accessibility settings, audio and narration preferences.
  • Parent lock state: the local PIN/recovery state used to protect the grown-up area.
  • App preferences: interface/audio preferences and version-specific “What’s New” dismissal state.

Parents may use a nickname instead of a child’s legal name.

4. Data collection, transmission and sharing

In the current release architecture, BrightQuest Kids does not transmit the learner profile, learning progress, parent settings or parent-lock data to a BrightQuest server. The developer does not operate a cloud account or remote learning-profile database for the current app.

The current app does not sell personal information, does not use child data for targeted advertising, and does not share child learning records with advertising, analytics or social-networking services.

The current Android release manifest does not request location, camera, microphone, contacts or advertising-ID permissions.

5. Children’s privacy

BrightQuest Kids is designed for children and parents. The current product architecture intentionally avoids child-facing advertising, public child profiles, social feeds, open chat, random chat, unnecessary sensitive permissions and online child-account creation.

Parent-only controls and external destinations are kept in the grown-up area. Parents should supervise any move from BrightQuest Kids to a browser, email app or platform store.

6. Device permissions and on-device services

The current Android app does not request permission to access precise or approximate location, camera, microphone, contacts, phone number, SMS, call logs, files/media, or advertising identifiers.

BrightQuest Kids can query the device for an available text-to-speech service so lesson text can be spoken aloud. Narration converts app text into speech; BrightQuest Kids does not record the child’s voice for this feature.

7. External links, app stores and third-party services

Parent-only links may open the official Baisalya website, the device email app, GitHub, LinkedIn, Buy Me a Coffee, Google Play or Microsoft Store. These destinations operate outside BrightQuest Kids and may process information according to their own privacy policies.

BrightQuest Kids does not attach or send a child’s learning record when opening those external destinations. Installation, store-account, crash, licensing or purchase information handled by Google Play, Microsoft Store, the operating system or browser is controlled by those services rather than by BrightQuest Kids.

8. Storage, retention and deletion

Local app data remains on the device until the parent uses an available profile/progress reset or deletion control, clears the app’s storage through the operating system, or uninstalls the app. Because the current app does not maintain a BrightQuest cloud child account, there is no remote BrightQuest learning-profile copy to request deletion from.

If future versions introduce optional cloud features, the retention and deletion process will be disclosed here before those features are released.

9. Security

BrightQuest Kids uses app-local and operating-system storage mechanisms available to the device. The parent gate separates grown-up settings from normal learner use, but it is not a replacement for the device lock screen or operating-system parental controls.

No electronic storage method can be guaranteed completely secure. Parents should keep the device, parent PIN and recovery code protected.

10. Parent choices and controls

  • Create, switch or remove local learner profiles where the app allows.
  • Reset supported learning progress and settings from the Parent Center.
  • Control app-wide music, game sounds and narration.
  • Configure healthy-play and accessibility preferences.
  • Protect parent-only controls with the local parent gate.
  • Clear app storage or uninstall the app using operating-system controls.
  • Contact the developer with a privacy question.

11. Purchases

BrightQuest Kids does not currently present a verified public paid class-pack listing on this website. If platform purchases are enabled in a future release, payment processing will be handled by the applicable store or another clearly disclosed provider. BrightQuest Kids will not require a child to enter payment-card details directly into the learning experience.

12. Changes to this policy

This policy will be updated before or when the app’s data practices materially change. Examples include adding cloud backup/sync, online accounts, remote analytics, voice recording, location, remote AI services, social features or production billing that changes how data is handled.

The “Last updated” date at the top of this page identifies the current version of the policy.
