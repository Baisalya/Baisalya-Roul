Settings and appearance#

Settings controls themes, density, backup, privacy links, support, manuals, onboarding, and local data reset.

Appearance#

Choose system, light, or dark brightness; an available palette; standard or high contrast; and comfortable or compact density.

Learning and documentation#

  • User manual: opens the complete offline guide. The website version is available at Complete user manual.
  • View onboarding again: replays the introduction without deleting local data.

Clear All Data#

Clear All Data removes known DevDesk-private local records, settings, policy acknowledgement, onboarding completion, and protected secret records. It does not delete external project folders, exported files, or information already sent to another service.

Responsive behavior#

Settings remains a single readable column on Android and a constrained content column on wide Windows screens.

Choose a readable configuration#

  • Follow system brightness when you frequently switch environments.
  • Use high contrast when normal palette boundaries are difficult to distinguish.
  • Use comfortable density for touch and compact density only when controls remain accessible.
  • Test the largest text size you expect to use.

Reopen learning material#

  • User manual opens the complete local guide.
  • View onboarding again replays the introduction without clearing data.
  • The website manual provides longer copyable examples and platform install links.

Downloads and Store access#

  • Windows: View DevDesk on Microsoft Store.
  • Android: closed testing — contact the developer through the public support page to join.
