Troubleshooting#

A workspace does not open#

  • Confirm the folder still exists.
  • Re-select the folder if Android permission was lost.
  • Check Windows path permissions or removable-drive availability.
  • Refresh the workspace registry.

Graph is empty or outdated#

  • Save the active Markdown file.
  • Rebuild the graph.
  • Check unresolved and ambiguous links.
  • Use Fit to center the canvas.
  • Confirm filters are not hiding nodes.

API request fails#

  • Check the destination URL and HTTPS.
  • Verify environment selection and variables.
  • Review authorization, cookies, and headers.
  • Check timeout, certificate, and network errors.
  • Confirm the endpoint accepts the selected body type.

File cannot be saved#

  • Confirm the selected location is writable.
  • Use Save As.
  • Check for external modifications.
  • Avoid invalid file names or paths.
  • Ensure storage is available.

UI looks cramped#

Resize the freeform or Windows window, close optional side panels, reduce display density, or collapse advanced options. DevDesk should not require a fixed orientation.

Data reset or recovery#

Use Settings backup before a major change. Clear All Data is destructive for DevDesk-private records but does not delete external folders.

Structured Knowledge proposal cannot apply#

  • Confirm files did not change after the preview was created.
  • Refresh analysis and review a new plan.
  • Check write permission.
  • Resolve malformed YAML before bulk metadata changes.
  • Restore from version control or backup if a prior external process partially changed the folder.

Android closed-test link does not open#

  • Use the Google account enrolled as a tester.
  • Accept the testing invitation first.
  • Open the link on the Android device.
  • Wait for Play Console changes to propagate.

Windows package is blocked#

  • Confirm it came from the official release destination.
  • Check the publisher/signing information supplied with the release.
  • Do not disable security controls for an unknown file.
  • Report the exact warning without attaching sensitive local data.
