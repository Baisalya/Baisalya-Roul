# DevDesk demo narration files

The featured website demo uses one silent video and optional synchronized audio
tracks. Add the finished narration files here using these exact names:

- `devdesk-demo-en.mp3` — English
- `devdesk-demo-hi-en.mp3` — Hinglish
- `devdesk-demo-or-en.mp3` — Odia + English

Each file must begin at the first frame and match the cleaned video's duration
of approximately 3 minutes 8 seconds. The website checks for these files and
enables each language automatically after upload; no HTML or JavaScript change
is required.

Export narration as MP3, 48 kHz, 128–192 kbps. Do not add the original screen
recording audio to the website video.
