Global options (place before the command):
  --quiet                      Suppress standard output; errors and exit codes remain.
  --no-color                   Disable ANSI color output (future-proof/no-op today).

Run options:
  --timeout <seconds>          Stop the child after 1-86400 seconds; exits 124.

API request options:
  --header "Name: value"       Repeat for multiple headers.
  --body <text>                Send a text body.
  --body-file <path>           Read a body from a file (maximum 5 MB).
  --body-stdin                 Read the body from stdin.
  --timeout <seconds>          1-300 seconds (default: 30).
  --no-redirect               Disable redirects.
  --output <path>              Save response bytes.
  --json                       Print a machine-readable response.
  --fail                       Exit 1 for HTTP 4xx/5xx responses.

All file paths passed to files commands are bounded to the selected workspace.
Create never overwrites an existing file. Run executes the exact program and
arguments supplied by the current user without opening the DevDesk app.
Phase D project verification runs only approved detected adapters and requires
--yes. Container and ADB mutation commands also require --yes; arbitrary shell,
container/pod exec, Kubernetes secret reveal, ADB root/fastboot, install/uninstall,
and device-wipe operations are intentionally not exposed. Phase E AI runs require
--yes, accept credentials only by environment-variable name, and never attach
workspace files automatically. Routine execution is review-first and never sends
an AI prompt automatically.
