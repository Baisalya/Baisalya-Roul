# Start here — Agent-ready workspace demo

This small project lets you see an AI agent use DevDesk's linked Markdown context before it changes code.

## The 10-minute outcome

1. Open this folder in DevDesk by opening `project.devdesk`.
2. See the linked project map in **Knowledge graph**.
3. Start **Settings → DevDesk Agent Connector** and copy the configuration for Codex or Gemini CLI.
4. Run a read-only request, then a small tested coding task.

## Your setup checklist

- [ ] The workspace title says **DevDesk Agent-ready Workspace Demo**.
- [ ] The Knowledge graph shows linked notes.
- [ ] The Agent Connector says **Running**.
- [ ] **Share redacted Markdown text** is on for the reading demo.
- [ ] Your AI client can answer the first prompt in [Demo script](docs/DEMO-SCRIPT.md).
