# Product Brief

## Release goal

Prepare a concise release summary for a local-first productivity tool. The summary must list the total work items, open items, and completed items without collecting user data.

## Success criteria

- The summary title is readable even when the input contains extra spaces.
- Counts are calculated locally from a supplied list.
- The change has focused automated tests.
- The release checklist is reviewed before publishing.
