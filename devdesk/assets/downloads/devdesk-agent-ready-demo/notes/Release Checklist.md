# Release Checklist

- [ ] Read the plan and linked Architecture note.
- [ ] Confirm the change has focused tests.
- [ ] Run the complete test suite.
- [ ] Review the agent's summary and changed files.
- [ ] Approve any Markdown proposal only after comparing it in DevDesk.
