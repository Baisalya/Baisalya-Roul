# Project brief

The project provides tiny, dependency-free helpers for presenting task
progress. The next requirement is a whole-number completion percentage that
uses the same validation rules as the existing text summary.

The implementation should be easy to review, preserve existing behavior, and
remain small enough to demonstrate a bounded AI context workflow.

See the [Architecture](ARCHITECTURE.md), the
[Add percentage task](../tasks/ADD-PERCENTAGE.md), and the
[Review checklist](../tasks/REVIEW.md).
