# Keyboard shortcuts

Available shortcuts depend on the active tool and platform. Tooltips show the authoritative action near each control.

## Common examples

- `Ctrl+S`: save in supported editors; in the workspace text editor, saves only the active workspace file with conflict protection
- `Ctrl+Shift+S`: Save As in supported editors; from a workspace text file, exports an independent copy
- `Ctrl+N`: new document in supported editors
- `Ctrl+O`: open file in supported editors
- `Ctrl+P`: quick switcher in Markdown Vault
- `Ctrl+K`: command palette in Markdown Vault
- `Ctrl+Shift+B`: toggle document browser in Knowledge Workspace
- `Ctrl+Shift+I`: toggle inspector in Knowledge Workspace
- `Ctrl+Shift+G`: open focused graph
- `Esc`: close a focused panel, sheet, or return to editor where supported

## Accessibility

Use Tab and Shift+Tab to move through focusable controls. Enter or Space activates focused buttons. Some Android keyboards may map modifier keys differently.

## Website manual shortcuts

- `/`: focus documentation search
- `Esc`: close search or mobile navigation
- `Alt+Left`: browser back
- `Tab` / `Shift+Tab`: move through controls

## Large text and freeform windows

If a layout feels cramped, enlarge the Android freeform window or Windows window, collapse optional panels, and keep advanced controls closed until needed. A usable workflow should not depend on one fixed screen size.
