# Quick API

Quick API is a lightweight request screen for one-off HTTP testing.

## Use it when

- You need to test one endpoint quickly.
- You do not need a complete saved workspace.
- You want to import or export a small collection.

## Steps

1. Select a method.
2. Enter an HTTPS URL.
3. Add headers, parameters, or body content.
4. Send the request.
5. Inspect the bounded response and history.

For environments, collections, protected variables, assertions, or reports, use **API Workspaces**.

## Multipart requests

Use the provided form-fields editor. Do not manually provide multipart boundary values.

## Privacy

Request content is transmitted to the endpoint you select. Review credentials, cookies, files, and body content before sending.

## Move to a workspace when the request grows

Switch to API Workspaces when you need:

- Multiple related requests
- Reusable environments
- Protected variables
- Assertions or extraction
- Organized history, reports, or examples
- A generated collection from OpenAPI
