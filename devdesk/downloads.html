Codex

Connect Codex

  1. In DevDesk, start the connector and select Copy Codex config.toml.
  2. Add the copied block in Codex MCP settings or your personal config.toml.
  3. Restart Codex, then run the first read-only demo prompt.

Gemini CLI

Connect Gemini CLI

  1. In DevDesk, select Copy Gemini CLI settings.json.
  2. Merge the copied devdesk entry into your mcpServers settings.
  3. Restart Gemini CLI and run /mcp to confirm it is connected.

Before installation

Use only the developer's Google Play closed-test page or the official Microsoft Store listing. Avoid modified third-party packages.

Before updating

Export a DevDesk backup and independently protect external project folders. Protected secrets are not part of supported portable backups.
