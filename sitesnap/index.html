SiteSnap

SiteSnap is the open-source Flutter/Android field-proof camera project by Baishalya Roul (Baisalya). It focuses on GPS and timestamped field documentation, project folders, notes, proof overlays and report-ready records. The published Android app built from this product direction is SurveyCam – Location & Geo Tag.

What SiteSnap is built for

SiteSnap is intended for field work where a photo or video needs context: where it was captured, when it was captured, which project it belongs to, and what note or overlay should travel with the record. The project is associated with SurveyCam’s GPS camera, geotag, timestamp and PDF proof-report workflows.
