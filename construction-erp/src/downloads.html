Windows installation

Office setup

  1. Download from Microsoft Store or the signed publisher installer.
  2. Check publisher identity and version.
  3. Install and open the app.
  4. Sign in with email/password.
  5. Confirm company, project and sync status.

Android installation

Site setup

  1. Install from Google Play when published.
  2. Open the app and sign in.
  3. Allow only permissions required for the feature you use.
  4. Select company and project.
  5. Make one test entry and confirm it reaches the authorized second device.
