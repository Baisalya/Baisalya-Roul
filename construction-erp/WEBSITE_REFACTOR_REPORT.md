- App alignment: `1.22.0+107`, database schema `30`.
- Marketing: buyer problem → seven-step workflow → budget control → role fit → walkthrough CTA.
- Product language: `Contract Value` and `Project Cost Budget` are separate everywhere.
- Manual: normal-user path is Tender → Project → Daily Work → Stock → Labour → Machinery → Report.
- Procurement: planned purchase is the default; emergency purchase is rare and receives stock in the same save.
- Budget: over-budget costs are blocked until an owner/admin approves the required increase.
- Trust: no fabricated usage numbers, savings percentages or customer testimonials.
- Social sharing: dedicated Construction ERP Open Graph image.
