Install safely

Use verified release channels.

For a free static website, keep large installers in Google Play, Microsoft Store or GitHub Releases and link to them from this page.

1

Check the source

Use the official store listing or the publisher’s verified release page.

2

Check the version

The current website is prepared for v1.22.0+107. Do not mix old clients with sync-v2 production rules.

3

Back up before upgrading

Create and test an encrypted backup, especially before the first database-encryption or major sync migration.

4

Finish setup

Sign in, select company and project, confirm permissions and complete one controlled sync test.

Windows installation

Office setup

  1. Download from Microsoft Store or the signed publisher installer.
  2. Check publisher identity and version.
  3. Install and open the app.
  4. Sign in with email/password.
  5. Confirm company, project and sync status.

Android installation

Site setup

  1. Install from Google Play when published.
  2. Open the app and sign in.
  3. Allow only permissions required for the feature you use.
  4. Select company and project.
  5. Make one test entry and confirm it reaches the authorized second device.

Not released

macOS and iPhone

The current Flutter production targets are Android and Windows. This website does not represent macOS or iPhone builds as available.
