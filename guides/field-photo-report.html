Turn site photos into a useful field report

A worked example for organizing GPS photos, writing useful field notes, checking timestamps and reviewing a SurveyCam PDF report.

Baisalya product guidance · Updated 7 October 2026

A folder of photographs can show what a site looked like, yet still leave the next person guessing what changed. A useful field report connects each photograph to a location, an observation and a next action. This guide uses a fictional drainage inspection to explain a repeatable workflow with SurveyCam. The example describes how to organize the work; exact controls can vary by app version.

Prepare the record before the visit

Choose one project name and use it consistently. For this example, the project is “North Block — Drainage” and the inspection is “Visit 03 — outlet check”. Avoid creating a new project for every photograph. Keeping repeat visits together makes it easier to compare conditions over time.

Decide which observations the report needs to answer: Is the outlet clear? Is water collecting upstream? Was the previously reported obstruction removed? Write these questions down before taking photographs. Otherwise, you may return with attractive images that cannot answer the inspection question.

Check camera and location permissions, device time and available storage. At the site, inspect the displayed location before relying on it. A location fix can be poor indoors, near tall structures or before the device has obtained a usable signal. A coordinate overlay records the device's reported position; it is not a surveyed boundary or a guarantee of measurement accuracy.

Capture context, then detail

  1. Take an overview showing the drainage line and nearby landmarks. This helps a reader understand the location without having attended the visit.
  2. Take a closer view showing the outlet condition. Keep the subject visible instead of filling the frame with an overlay.
  3. Take a detail photograph of any blockage or defect. Include a useful reference object when appropriate, while avoiding claims of precise dimensions from an uncalibrated photograph.
  4. Review the images before leaving. Retake blurry or obscured photographs while the location is still accessible.

Use the same approximate viewpoint on a later visit. Comparing an overview with an unrelated close-up can suggest a change that is only a framing difference. Label what the camera actually shows and distinguish it from an explanation you have not verified.

Write notes that separate observation from action

“Problem at drain” is too vague to help a reviewer. A better note states the exact subject, the visible condition and what needs checking next. The following example is fictional and can be adapted to your own inspection:

Project: North Block — Drainage
Visit: 03 — outlet check
Photo: Outlet, downstream side
Observation: Loose debris visible across the outlet opening.
Follow-up: Clear debris and photograph the same viewpoint.
Unconfirmed: Cause of upstream standing water.

The “Unconfirmed” line matters. A single photograph does not prove the cause of standing water. It tells the next person what remains to be investigated. Add a note when the GPS fix or timestamp needs qualification rather than silently presenting an uncertain overlay as definitive evidence.

Select and review the PDF report

SurveyCam supports project folders, notes, watermarks and PDF photo reports. Select photographs that answer the inspection questions, then arrange them so the reader sees context before detail. Include the observation and follow-up alongside the relevant photograph. Ten near-identical images usually communicate less than three well-selected views with clear notes.

Open the exported PDF outside the app before sharing it. Check that text is readable, photos have the expected orientation and each page belongs to the intended project. Confirm the report contains the relevant visit rather than an earlier test capture. If a caption was cut off or a photograph is missing, fix the record and export again.

Keep the original record and a clear handover

A PDF is a convenient review copy. Keep the original captures and project records according to your team's process as well. A local project folder alone does not protect you against device loss. Store an independent copy of important reports in an approved location and use a filename that carries the project, visit and date.

Before sending, check whether the images reveal faces, vehicle numbers, private locations or information unrelated to the task. Share only the views the recipient needs. After the follow-up, produce a new report with the matching viewpoint and explain what changed; do not overwrite the earlier record merely to make the project look complete.
