Local-first, recovery-aware

Keep working offline. Prepare for the day a device is lost.

Daily work is stored locally first. Owners can use encrypted Google Drive backup and a separately saved recovery code to restore an authorized workspace on a replacement device.

1

Save locally

Allowed work is written to the active shop database even when internet is unavailable.

2

Back up securely

Pending changes and encrypted backups move when the account, connection, and permissions are ready.

3

Restore deliberately

The correct Google account locates the backup; the matching recovery code unlocks it.

The recovery code matters.

Keep it outside the same phone or computer. A cloud backup may not be recoverable without its matching code.

Straight answers

Before you install ShopPilot

These answers reflect the current Windows release and Android closed-testing channel.

Where can I install ShopPilot?

Windows is available from the Microsoft Store. Android is available through the Google Play listing for closed testers.

Why does Android say closed testing?

The Android build is being distributed to enrolled testers while release feedback is collected. If the listing is not available to your account, use the tester invitation or enrollment provided by the ShopPilot team.

Does it work without internet?

Normal permitted shop work is designed to save locally first. Cloud backup, account verification, team delivery, and some shared operations require internet.

Can one owner manage multiple shops or branches?

Yes. Separate workspaces keep businesses apart, while branches organize locations inside a business. Visibility and staff work are controlled by branch and permission.

Does ShopPilot replace an accountant?

No. It is designed so a shopkeeper can operate billing, stock, daily हिसाब, and management reports without accounting software expertise. Statutory accounts and tax filing still require appropriate professional review.

Where is business data stored?

Each workspace has its own encrypted local database. Optional cloud and team features use the services described in the Privacy Policy.
